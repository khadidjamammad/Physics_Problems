# 12. Transformer Currents

Given:

- Number of primary turns, Np = 1000
- Number of secondary turns, Ns = 200
- Primary voltage, Vp = 120 V
- Secondary current, Is = 3 A

---

## Step 1: Find Secondary Voltage

Use the transformer equation:

Vs / Vp = Ns / Np

Substitute the values:

Vs / 120 = 200 / 1000

Vs / 120 = 0.2

Vs = 120 × 0.2

Vs = 24 V

---

## Step 2: Find Primary Current

Use the current relationship:

Ip / Is = Ns / Np

Substitute the values:

Ip / 3 = 200 / 1000

Ip / 3 = 0.2

Ip = 3 × 0.2

Ip = 0.6 A

---

# Final Answers

- Secondary Voltage = 24 V
- Primary Current = 0.6 A
