# Light Speed Measurement Using a Microwave Oven

## Objective

Estimate the speed of light using a microwave oven and compare the result with the accepted value.

---

## Theory

Microwaves inside a microwave oven form standing waves. These waves create regions of maximum heating called antinodes.

When a chocolate bar or slices of cheese are placed inside the microwave, melting occurs at these hot spots.

The distance between two adjacent melted spots corresponds to half the wavelength:

λ = 2d

where:

- λ = wavelength (m)
- d = distance between melted spots (m)

The speed of light is then calculated using:

c = fλ

where:

- c = speed of light (m/s)
- f = microwave frequency (Hz)
- λ = wavelength (m)

---

## Given Data

Typical microwave frequency:

f = 2.45 GHz

f = 2.45 × 10⁹ Hz

Measured distance between melted spots:

d = 6.1 cm

d = 0.061 m

---

## Calculate the Wavelength

λ = 2d

λ = 2(0.061)

λ = 0.122 m

---

## Calculate the Speed of Light

c = fλ

c = (2.45 × 10⁹)(0.122)

c = 2.989 × 10⁸ m/s

c ≈ 298,900,000 m/s

---

## Accepted Value

Accepted speed of light:

c₀ = 300,000,000 m/s

---

## Percentage Error

Percentage Error = |Measured − Accepted| / Accepted × 100

Percentage Error

= |298,900,000 − 300,000,000| / 300,000,000 × 100

= 0.3667 %

≈ 0.37 %

---

## Results

| Quantity | Value |
|-----------|-----------|
| Frequency | 2.45 × 10⁹ Hz |
| Distance Between Melted Spots | 0.061 m |
| Wavelength | 0.122 m |
| Measured Speed of Light | 2.989 × 10⁸ m/s |
| Accepted Speed of Light | 3.00 × 10⁸ m/s |
| Percentage Error | 0.37% |

---

## Conclusion

Using a microwave oven and a chocolate bar, the speed of light was estimated to be:

298,900,000 m/s

The accepted value is:

300,000,000 m/s

The percentage error was only 0.37%, showing that a simple household experiment can provide a surprisingly accurate estimate of the speed of light.
